# OpsForge

OpsForge 是面向运维与云原生技术学习的实训平台，将知识学习、动手练习、故障分析、考试测评和学习记录集中在一个工作台中，适合日常技能训练、面试准备及专题复习。

## 题库与知识学习

题库按技术模块、知识点、难度和题型组织，覆盖 Linux、网络、容器、Kubernetes、数据库、监控、日志及自动化等方向。用户可以浏览模块课程、筛选和搜索题目，结合题目材料、参考答案与解析梳理知识。

支持九类题型：单选、多选、判断、填空、简答、编程、实操、故障场景和综合项目。不同题型使用对应的作答方式，兼顾基础知识、实际操作和综合方案能力。

## 练习工作台

在同一页面阅读任务、查看给定材料、编辑代码与配置文件，并记录解题思路和操作证据。支持多文件产物编辑、草稿保存、提交及检查结果查看，便于持续完成一项练习。

故障场景侧重现象判断、证据分析和修复思路；综合项目侧重完整交付、验证与回退方案。文档类任务可以编辑并提交指定材料，等待人工审核。

## 实验与判分

具备对应环境和题目支持时，可使用实验工作区执行操作、查看输出并核验结果。题目可以围绕代码运行、配置产物或资源状态设置检查。

支持自动判分、状态验收及人工审核题提交。检查结果展示通过情况和反馈；文字题可对照参考要点进行自评。自动结果、人工待审状态和自评分开记录，方便辨别练习结果。

## 学习记录与复习

保存历史提交、作答内容、代码或配置文件及检查反馈，便于回看解题过程。支持题目收藏和待复习题目管理，帮助集中处理薄弱知识点。

提供题目笔记，可按题目、模块或笔记内容搜索，并区分当前笔记与历史提交时的笔记，保留不同阶段的学习思路。

## 考试测评

按模块、题型、难度、题数和时长组卷，也可选择随机变式。考试期间收起提示与答案，保存作答进度，交卷后查看成绩、题目结果和历史考试记录。

可自动验收的题目参与对应判分，文字面试题的自评结果单列展示；缺少自动验收规则的题目不会直接加入新的考试试卷。

## 题库管理

支持新建和编辑自定义题目、批量导入 JSON 题库，以及导出自定义题目迁移文件和资料归档。新增或更新的自定义题目进入待审校流程，完成审校后再发布。

题目使用编号与版本关联，保留旧版本及历史提交。内置题库更新遇到本地编辑冲突时保留本地内容，方便核对和维护个人题库。
